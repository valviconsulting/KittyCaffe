# Продуктове бачення та дорожня карта «Мур-Лате» (`KittyCaffe`)

**Статус:** Затверджено власником (26 листопада 2026 року) на основі консолідованого аудиту та `MUR-LATTE-AUDIT-01`  
**Слоган:** *«Маленька кав’ярня. Великі історії»*  
**Цільовий пріоритет платформи:** Постійний **HTTPS-деплой** із фокусом на **мобільну версію (Mobile-First + PWA)**.

---

## 1. Чотири опори продукту

1. **Тактильне приготування** — приємні ручні дії без стресу, видима реакція напою, рівноцінне керування пальцем, мишею й клавіатурою (включно з режимом без утримання).
2. **Дитина як співавторка** — авторські рецепти, лате-арт, власний малюнок на стіні кав’ярні або власний створений гість, який реально заходить у гру.
3. **Дружба й теплі історії** — гості зі своїм характером, локальні листи, невеликі сюжетні глави (3–4 ігрові дні), щоденник спогадів.
4. **Затишний світ без тиску** — жодних таймерів програшу, штрафів за пропуск днів, реклами чи нав’язливих очікувань; Марципан отримує лише котячі смаколики й ласку.

## 3. Backlog майбутніх етапів (Етап 5+ — після підтвердження інтересу)

Ці великі ідеї **збережені в плані розвитку**, але свідомо відкладені до завершення Кроків 01–07, щоб не розмивати базовий ігровий цикл:

- **🌿 Затишний садок** — вирощування м’яти, полуниці, ромашок та сезонних ягід для кав’ярні.
- **🥐 Пекарня з тістом** — розширена тактильна випічка (формування, глазурування, прикрашання).
- **🏡 Літня тераса та містечко** — нові локації, вуличні столики, прогулянки гостей.
- **🔮 Загадки, «Здивуй мене!» й колекція таємних рецептів** — розширення реіграбельності після впровадження Day Director.
- **☁️ Опціональний бекенд / хмарна синхронізація** — потрібен **лише** якщо в майбутньому знадобиться автоматична синхронізація прогресу між кількома пристроями (телефон + планшет + ПК) або віддалений батьківський кабінет; на етапі HTTPS + мобільна PWA достатньо `localStorage` + експорт/імпорт JSON (нуль серверних витрат і повна приватність).

## 4. Мобільна стратегія та HTTPS-деплой

- **PWA (Progressive Web App)**: після деплою на постійну HTTPS-адресу (Cloudflare Pages / Netlify / GitHub Pages) гра встановлюється на домашній екран телефону/планшета як повноекранний застосунок.
- **Мобільна вага**: конвертація PNG-асетів (`5.64 MB`) у WebP + ліниве завантаження модалок зменшить початкове завантаження у кілька разів.
- **Захист прогресу при переїзді**: перенесення дитини з `localhost` на постійний HTTPS-домен виконується **тільки після** додавання та перевірки експорту/імпорту JSON (`SOL-001`), щоб жоден прогрес не загубився через зміну `origin`.
