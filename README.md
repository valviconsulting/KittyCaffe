# ☕ Мур-Лате (`KittyCaffe`)

Затишна інтерактивна 2D-вебігра у стилі акварельної казки (Studio Ghibli storybook aesthetic) для дитини 9 років — кав’ярня-кондитерська для тваринок з українським інтерфейсом, без стресового таймера й програшу.

## Основні можливості (Етапи 1–3)

- **Акварельна зала кав’ярні**: панорамний інтер’єр (`21:9`), жива зміна погоди за вікном (`☀️ Сонячно`, `🌧️ Дощ`, `❄️ Сніг`), сплячий кіт-помічник **Марципан** (мурчить від погладжування), 6 постійних гостей + особливий гість **«🎒 Котик-мандрівник»**.
- **3 робочі станції бариста**:
  - **☕ Кава та какао**: прозора чашка з анімованими шарами, `🎨 Лате-арт` (малювання по пінці на HTML5 `<canvas>` пензлями й трафаретами) та відкривний рецепт **`🍵 Матча-Лате`** (8-й слот сітки `4×2`).
  - **🍹 Дитячі коктейлі**: високий келих (`Дитячий Мохіто`, `Коктейль «Санрайз»`) та анімований блендер для мілкшейків зі збитими вершками.
  - **🥐 Випічка**: вітрина десертів (`Круасан` із міні-пічкою, `Печиво`, `Пончик` із глазур’ю й посипкою) та відкривний **`🥕 Морквяний кекс`**.
- **🏃 Замовлення «Із собою»**: декор паперового або прозорого стаканчика наліпками (7 базових + 5 рідкісних золотих стікерів від Котика-мандрівника) й теплими побажаннями на манжеті.
- **✨ Секретний напій дня**: 3-кроковий конструктор власного рецепта з живою візуалізацією, генератором назв, крейдяною табличкою в кав’ярні та підвищеною нагородою `+25 🐟`.
- **🛍️ Магазин і Гардероб Марципана**: 5 комбінованих аксесуарів (голова + окуляри + шия), 4 елементи декору інтер’єру (включно з музичною скринькою на Web Audio API) та 2 відкривні рецепти.
- **📸 Альбом дружби**: полароїд-картки гостей, шкала `0/3 ❤️`, секретні факти, постійні `+5 🐟` чайові та колекція сувенірів на «Поличці друзів».
- **Звук і збереження**: синтезовані звуки та мелодія музичної скриньки через **Web Audio API** (жодних зовнішніх аудіофайлів), повне збереження прогресу в `localStorage` (`mur_late_save_v1`, схема `v3`).

## Швидкий старт

```bash
npm install
npm run dev      # Локальний сервер розробки (Vite)
npm run lint     # Статичний аналіз (oxlint)
npm run build    # Перевірка типів TypeScript + production-збірка
npm test         # Доменні модульні тести (Node native TypeScript)
```

## Архітектура та мультиагентна розробка (Antigravity)

Проєкт структуровано для командної ШІ-розробки в **Google Antigravity** з чітким розділенням ролей **Архітектор/Оркестратор** (`Gemini 4 Neon xHigh` / `Gemini 4 Carbon`) та **Виконавець** (`Gemini 4 Carbon` / `Gemini 4 Hydrogen`):

- [AGENTS.md](./AGENTS.md) — завжди активні правила репозиторію, інваріанти та критерії приймання.
- [docs/ARCHITECTURE.md](./docs/ARCHITECTURE.md) — системна архітектура, схема модулів, контракти стану/сховища, оркестрація агентів і карта техборгу.
- [docs/AUDITS.md](./docs/AUDITS.md) — журнал незалежних аудитів (підготовлено під прийом аудиту від **ChatGPT Sol 6.2**).
- [.agents/skills/](./.agents/skills/) — модульні інструкції для Архітектора, Виконавця, обробки зовнішніх аудитів і візуального QA.
